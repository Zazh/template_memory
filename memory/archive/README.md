# Архив закрытых бэклогов

Одна строка на запись каталога: итог и уроки, которых нет в живых доках. Полный итог, решения
и Handoff-ы — в самой записи (`archive/<каталог>/00-backlog.md`). Читать только по ссылке.

Правило: строка добавляется при архивации бэклога (`process/BACKLOG-GUIDE.md`, закрытие по DoD);
в «Уроки» — только те 🔴, что не попали в живые доки и `process/PROJECT.md`, дословно.
