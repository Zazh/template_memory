## Конвенция {#convention}

- **Figma — источник истины облика.** Код расходится с макетом только по записанной дельте
  (`#deltas` ниже) либо по канону дорисовки (`#canon`); иное расхождение — находка критика.
- **Актуализация — на месте:** правятся существующие артборды (экземпляры кита сохраняются);
  снимок ДО правок — страница «Архив · ‹флоу› ‹дд.мм›».
- **Запланированное** — секция «‹Флоу› · СКОРО (‹бэклог›, ещё не в коде)» с плашкой рядом с
  основной; после выката артборды переезжают в основную секцию, прежние — в архив, плашка
  снимается.
- **Состав:** основные состояния + меняющие вид (однотипные ошибки — одним примером); у
  каждого состояния пара Desktop ↔ Mobile; порядок на холсте — порядок сценария; недостижимое в
  коде состояние не рисуется; образцы данных обезличены.
- **Статусы строки `#screens`:** **актуален** — совпадает с кодом с точностью до дельт;
  **СКОРО** — нарисовано, в коде нет; **устарел** — код ушёл дальше контракта, сверять с кодом
  и дельтой; **архив** — только на архив-странице; **нет макета** — канон дорисовки.
- Новый экран или флоу в Figma — строкой сюда (`#screens`) в том же коммите, что и Handoff
  Figma-блока; отдельный `DESIGN.md` внутри блока бэклога не заводится.

## Канон дорисовки {#canon}

Чего в макете нет — делается по этим правилам и показывается владельцу на чекпоинте.

- **Состав кита, а не новые сущности:** экран без макета собирается из примитивов кита;
  мобайл экрана, нарисованного только на Desktop, — шит или модалка кита.
- **Текст — только ступенями кита**, палитра — один токен на роль; сырой hex — только палитра
  данных и исключения из `#tokens`.
